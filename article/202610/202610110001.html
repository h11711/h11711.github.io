我把初中三年的学习资料整理成了一个仓库

2026年10月11日 阅读约 4 分钟

初中三年攒下来的资料，散在网盘、U 盘、聊天记录和打印店里。 想找一份八下的地理评价卷，得翻半天。于是我把它们收拢到了一个 GitHub 仓库里。

仓库里有什么

按学科分目录，目前覆盖九科：

  • 语文、数学、英语
  • 物理、化学、生物学
  • 历史、地理、道德与法治

文件以 PDF 为主，也有少量其他格式。 每个学科下面按资料类型再分一层，比如"资源与评价""试卷""笔记"之类。 完整的目录清单放在仓库根目录的 STRUCTURE.txt 里，想看全貌可以直接翻那个文件。

为什么有些文件不在仓库里

部分 PDF 体积不小，直接塞进 Git 会让仓库越来越臃肿，克隆一次要等很久。 所以这些文件改成放在外部存储服务上，仓库里保留一个说明文件，指向对应的下载链接。

比如这一条： 

/地理/资源与评价/2025资源评价八下地理.pdf
==> 本文件指向外部存储服务
==> https://1832674303.share.123pan.cn/...

打开仓库里的同名文件，就能看到跳转链接。 这样仓库本身保持轻量，资料又不会丢。

怎么用

直接浏览或者克隆都行： 

git clone https://github.com/h11711/junior-high-materials.git

然后按学科进入对应目录。找资料之前建议先看一眼 STRUCTURE.txt， 比一个个点进去快。

几点说明

  • 仓库只做整理和备份，不保证资料的完整性和时效性
  • 资料版权归原作者和出版方所有，如有侵权请联系删除
  • 请勿用于商业用途

最后

整理这件事本身没什么技术含量，就是把散的东西归到一处。 但整理完之后，找一份资料从"翻十分钟"变成"点两下"，这个差别还是挺大的。

如果你也在读初中，或者家里有正在读初中的孩子，这个仓库的结构可以直接拿去用。 仓库地址：github.com/h11711/junior-high-materials
